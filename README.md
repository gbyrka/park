# Park

Prosta, pozbawiona dźwięków gra parkingowa 2D działająca w przeglądarce.

## Jak grać

- `↑` / `↓` — przyspieszanie i cofanie
- `←` / `→` — skręcanie
- `R` — rozpoczęcie od nowa

Wjedź całym samochodem na zielone miejsce i zatrzymaj się, aby zdobyć punkt. Na zdobycie jak największej liczby punktów masz 60 sekund.

## Uruchomienie

Otwórz `index.html` w przeglądarce. Projekt nie wymaga instalowania zależności ani procesu budowania.
